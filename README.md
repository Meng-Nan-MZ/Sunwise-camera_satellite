# Satellite Dataset Studio V2.5.2

Windows 本地离线卫星图像与姿态数据生成工具。V2.5.2将首次启动默认主题改为浅色，保留用户已保存的主题选择；延续原创遥感卫星、SAR 雷达卫星与哈勃去重后的19套可选模型；任务与结果页支持右键删除任务及本地文件夹，删除原图时同时确认关联噪声版本。保留各采集方式的拖动规则、Corporate Clean界面、批量数量选择及深浅主题。启动窗口约1120×680逻辑像素，按屏幕可用区域和缩放自动收紧。

## 启动

双击 `tools/start-desktop.cmd`。当前版本2.5.2，开发程序位于 `var/build/desktop-2.5.2/`。本轮更新源码与可运行开发版，不制作安装包或压缩包。各版本构建分别留存，不替换正在运行的旧版本。

同一工作区只运行一个服务；启动新版前关闭使用同一工作区的旧窗口。开发版工作区为 `var/workspace/`，安装版为 `%LOCALAPPDATA%\SatelliteDatasetStudioV2\workspace`。V2 不读取 V1 旧协议数据，请勿把 V1 目录作为 V2 工作区。

## 数据采集

本轮加入用户提供的原创遥感卫星和SAR 雷达卫星，保留源GLB的材质与贴图。模型选择只保留一套哈勃；重复的旧标识与原资产仅用于既有任务兼容，不重新解释旧任务参数。自制与公开收集资产保留原作者数值尺度、按仿真米制使用，未独立校准实星工程尺寸；来源和尺度说明在技术详情及每帧模型元数据中保存。用户自制资产不被标注为公开许可素材。

顶部选择模型、采集方式和输出文件夹；左侧查看真实模型，预览标题与视角、辅助操作合为一栏，右侧配置拍摄参数。右栏底部固定显示输出摘要、重置和生成按钮，左侧展示区延伸到下沿。

- 批量模式可点击100、500、1000或“自定义”，填写“生成图片数量（张）”，主按钮同步显示数量。随机姿态默认1000张，两种序列默认120张，均是可修改的初始值；批量数量为1–100000整数，起止姿态至少2张。无效输入会提示并阻止提交，单张模式固定1张。
- 单张、随机姿态批量、自动旋转序列、起止姿态序列均可使用固定拍摄距离，默认20 km。滚轮、距离输入和滑杆双向同步，范围10–30 km；距离显示最多两位小数，内部保留完整精度并用于正式出图。
- 随机姿态批量和自动旋转序列还可选择原有自动变距，此时预览距离仅作参考，禁用滚轮调距与重置距离，不更改自动策略。新任务记录所选距离策略；旧任务不补写或重新解释。
- 所有采集方式都支持在彩色模型视角拖动。单张及起止姿态序列的“拖动调姿”实时改变卫星朝向并同步右侧XYZ，单张出图使用该姿态；随机姿态批量与自动旋转序列的“模型预览”仅改变独立的观察姿态，不写入右侧技术姿态、种子或正式采集参数。离开模型预览或切换模型、采集方式、页面后复位观察姿态。其相机距离、方向和视场与“拍摄视角”一致，保留彩色材质与观察补光。合并后的预览栏提供坐标轴、“旋转预览”和“重置距离”；重置距离回到20 km，卫星姿态保持不变，辅助轴不进入正式图片。
- “旋转预览”默认关闭，在“拖动调姿”和自动采集方式的“模型预览”视角均可使用。它绕世界竖直轴缓慢旋转，从上方向下看为逆时针，仅用于观察，不改变XYZ角度、拍摄距离或任务参数；关闭或切换拍摄视角后恢复设定姿态。开始拖动或编辑XYZ会停止旋转；单张及起止模式从设定姿态继续编辑，随机姿态及自动旋转模式仅改变独立观察姿态；切换模型、采集方式或页面也会停止。起止姿态序列处于预览状态时禁用旋转预览，避免叠加动画。
- 拍摄设置提供常用参数；种子放在“更多参数”，四元数和坐标说明放在只读“技术详情”。噪声提供无、轻微、中等、自定义，只有自定义显示专业数值。重置仅影响采集草稿，已提交任务保持冻结。

起止序列播放或暂停时可直接拖动，退出序列预览并从当前显示帧继续编辑；已保存起止端点不自动改变，仍需点击对应端点的“使用当前姿态”。直接点击“退出预览”则恢复之前的手动姿态。起止姿态序列至少两帧，包含首尾，沿最短旋转路径过渡；预览期间仍可调整整段固定距离，端点姿态保持不变。相同端点不表示转满一圈，当前没有整圈、多圈或指定方向采集。

“随机姿态批量”“自动旋转序列”“起止姿态序列”分别对应原coverage、sequence、custom_sequence；拖动观察保持原采样和插值算法。“旋转预览”不会生成旋转序列任务。

小窗口下，坐标轴、旋转预览及重置距离收进“预览辅助”，展开后操作。

## 任务与结果

左侧按任务信息、模型和状态筛选已加载任务，可以继续加载较早记录。右侧显示所选任务的真实原图/噪声图，支持逐帧翻页、显示缩放和平移；打开图片或所在文件夹可检查原文件。技术ID、路径和保存参数默认折叠，显示内容来自冻结记录。

追加噪声在独立窗口设置，参数与采集草稿分开；直接复用来源原图、姿态和标签，不重新渲染或复制。相同来源与相同参数/种子可复现结果。备份时同时保留原始任务和噪声版本，并维持同级关系。

任务串行执行，可以取消，完整帧保留；没有暂停或断点续跑。新采集期间保持工作台打开。

右键最近任务（键盘可用Shift+F10）选择“删除任务及文件…”，核对模型、数量、时间和完整文件夹路径后确认。删除原图会列出并一并删除关联噪声版本；单独删除噪声版本保留原图和其他版本。删除直接移除任务文件，不进入回收站。排队/运行任务或活动关联版本须先取消并等待结束。确认期间若关联任务发生变化，必须重新确认。目录归属不明或存在链接时拒绝删除；文件占用等失败保留任务记录供重试，已删除的部分文件不会回滚。

## 保存位置与主题

桌面顶部“更改”直接打开系统文件夹选择器，选定后立即保存；支持中文、空格和其他磁盘。取消或保存失败保留原位置，可重试。“恢复默认”和目录帮助位于设置页。浏览器保留路径输入与保存回退。新任务冻结提交时的位置，历史和排队任务继续使用原路径；追加噪声放在来源旁边。数据库、设置和日志仍位于工作区。

“设置”可切换深色/浅色，并由工作区保存，重启后继续使用。主题只改变界面，不改变采集背景、光照或正式PNG。

## 渲染、坐标与历史

新采集只使用工作台 WebView2 内的 Three.js，沿用 `threejs-detail-v1`，不需要 Blender、生产端 Node.js 或额外浏览器。正式图片为1024×1024、8位灰度PNG，逐帧保存YOLO与姿态JSON。

- 世界/零姿态本体系：X向图像右、Y朝观测相机、Z向图像上，左手系。
- 观测相机系：X向图像上、Y向图像左、Z沿光轴朝目标。
- 对外四元数为主动 local-to-world 的 `{W,X,Y,Z}`；默认观测相机为 `{W:0.5,X:0.5,Y:-0.5,Z:0.5}`。
- 协议继续使用 `satellite-pose-4.0` / `lh-client-world-v2`；新增距离策略属于任务请求元数据。

已完成的V2系列Blender任务仍可查看并基于已有原图追加噪声，不改写原文件。新版不执行Blender采集或自动转换旧任务。离线模型制作工具、购买素材、旧版本及本机Blender安装保留，应用发行只需准备好的GLB。

## 工程与开发

`apps/desktop` 为WPF/WebView2宿主，`apps/ui` 为React/TypeScript/Three.js，`python/src/satellite_studio` 提供领域数学、任务、网页桥接和校验。运行库、构建、日志和数据进入 `var/`。`KIMI/` 是独立工作空间，Git忽略，不参与本项目处理。

开发依赖Python3.11+、Node.js24、.NET8，以锁文件为准。开发脚本只读取 `var/runtime.json` 的Python路径或 `SATELLITE_PYTHON`；遗留Blender配置不参与运行。Git不包含购买模型和本地运行库，仅下载源码还需准备授权GLB和开发环境。

所有GLB留在本地，不作为Git二进制提交。仓库保存各模型来源、归属说明、哈希、规范化变换和独立几何审计。`tools/import_curated_models.py` 可重建公开收集资产，`tools/import_custom_models.py` 可从用户原始文件重建本轮两个自制模型。两者仅用于开发阶段离线准备资产，所用Blender不进入软件运行依赖。

```powershell
python -m pip install -e ./python
pnpm --dir apps/ui install --frozen-lockfile
pnpm --dir apps/ui run test
pnpm --dir apps/ui run build
./tools/test-python.ps1
./tools/build-desktop.ps1
```

V2.5.2 的原生主题验收见[验证记录](docs/verification-v2.5.2.md)。`tools/verify_v251_models.cjs` 和 `tools/verify_v250_models_delete.cjs` 分别保留 V2.5.1 模型接入、V2.5.0 模型与任务删除的验收范围；其他带版本号的验收工具和报告用于追溯对应版本，复现时应使用相应版本源码。工具分类见[离线资产与验收说明](tools/OFFLINE-AUTHORING.md)。Node.js/Playwright仅用于开发验收。GLB-only发行见[打包说明](packaging/README.md)，本轮没有新安装包。
