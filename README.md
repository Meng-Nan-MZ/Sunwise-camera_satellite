# Satellite Dataset Studio V2.4

Windows 本地离线卫星姿态图像生成工具。V2.4 采用浅色两页界面：在“生成数据”配置预览，在“任务与结果”查看图像和追加噪声。新采集统一使用 Three.js，程序启动、正式出图和应用发行不再需要 Blender。

## 启动

本机开发构建完成后双击 `tools/start-desktop.cmd`。当前版本 2.4.0，可执行文件在 `var/build/desktop-2.4.0/SatelliteStudio.Desktop.exe`。本轮更新可运行开发版，不制作安装包或压缩包。

开发构建按 `var/build/desktop-<版本>/` 分别留存，构建与启动脚本读取同一工程版本。使用现有工作区时，先关闭旧版本窗口，再启动新版，避免两个服务同时使用同一数据库。

历史 V2.0 安装包位于 `var/releases/`，不包含后续开发的新功能；后续稳定发行时再统一打包。V2 系列安装目录为 `%LOCALAPPDATA%\Programs\SatelliteDatasetStudioV2`，数据目录为 `%LOCALAPPDATA%\SatelliteDatasetStudioV2\workspace`，可与 V1 共存。

开发模式程序数据保存在当前工程 `var/workspace/`，默认数据集在其 `jobs/` 下；可在界面更改之后采集的数据集位置。V2 不导入 V1 任务；请勿将 V1 数据目录指定为 V2 工作区。

## 坐标和输出

- 世界/零姿态本体系：X 向图像右、Y 朝观测相机、Z 向图像上，左手系。
- 观测相机系：X 向图像上、Y 向图像左、Z 沿光轴朝目标。
- 四元数为主动 local-to-world 变换，对外固定 `{W,X,Y,Z}`；默认卫星为 `{W:1,X:0,Y:0,Z:0}`，默认观测相机为 `{W:0.5,X:0.5,Y:-0.5,Z:0.5}`。
- JSON 位于 `poses/`，包含 `Location.SatQuat`、`Location.CamQuat` 和坐标说明。协议为 `satellite-pose-4.0` / `lh-client-world-v2`。
- Three.js/Blender 的引擎坐标由内部转换层处理，模型二进制和零姿态外观保持一致。用户无需切换坐标模式。
- 正式图片为 1024×1024、8 位灰度 PNG，辅助轴和界面控件不进入图片。

详见 [使用指南](docs/user-guide.md)、[协议说明](docs/architecture/interfaces.md)、[V2.4 验证记录](docs/verification-v2.4.md)。各历史验证记录保留原版本含义。

## 数据集保存位置

底部点击“更改”，输入已有文件夹路径，或点击“选择文件夹”打开系统选择窗口，再点击“应用”。支持中文、空格和其他磁盘，选择会在重启后保留；“恢复默认”可返回程序原本的数据集位置。未应用的输入不改变已保存的位置。普通浏览器中可手动输入并应用，系统文件夹选择由桌面程序提供。

新采集任务在选定位置创建独立任务子文件夹；已提交、排队和历史任务继续使用各自原位置，不搬动旧数据。追加噪声版本仍与原图任务放在一起，以保持来源引用完整。原图、姿态和标签不会被复制或改写。

数据库、设置和日志继续保存在程序工作区。保存位置不可写或已断开时会明确报错，不自动改存其他盘。浏览旧任务需要保留其数据目录；备份任务历史时同时备份工作区数据库与各数据集目录，原图和噪声版本保持同级。

## 网页正式采集

生成页左侧选择模型和模式并检查三维预览，右侧配置常用参数，“高级参数”内保留种子、详细光照/噪声与坐标说明。底部固定显示保存位置、任务摘要和生成按钮。模型观察不改变采集相机，切换页面和编辑草稿不改变已提交任务。

正式采集复用 WebView2 内的独立隐藏 Three.js 画布，沿用 threejs-detail-v1 的灯光、材质、抗锯齿和缩采样配置；浅色主题不改变正式 PNG。网页采集期间保持工作台打开，连接丢失、取消或窗口关闭时明确结束当前尝试。每帧继续记录实际后端、资产摘要和细节配置。

已完成的 V2 系列 Blender 任务仍可查看，并可基于已有完整原图追加噪声，原快照与文件不改写。V2.4 不再执行 Blender 任务，也不自动转换旧任务；若要重新采集，应明确创建新的网页任务。历史排队的 Blender 采集会给出不支持提示。

## 原图与噪声版本

关闭像素噪声后，新采集只保存原图、YOLO 标签和姿态 JSON。选择已完成任务，调整噪声参数与随机种子，点击“基于原图生成噪声版本”，直接处理原图，不重复渲染或复制原图与标签。每组噪声作为独立任务保留，可比较结果并查看参数和来源。

噪声版本目录通过相对引用复用原始任务，移动或备份时需要同时保留来源任务。已有 V2/V2.1 配对文件仍可查看，不会自动删除旧噪声副本。任务与结果页独立提供进度、取消、干净图/含噪声图和追加噪声。

## 自定义姿态序列

选择“自定义姿态序列”，设置起始姿态、结束姿态与帧数（至少2帧，包含首尾）。可以将当前手动姿态记录为端点，播放或逐帧查看过渡，再提交整批任务。距离、相机和光照在同一批内固定。

姿态沿最短路径过渡；相同起止姿态得到静止序列，不表示转满一圈。原有单张、全姿态采样和随机连续序列继续保留。预览不覆盖端点，整批提交固定使用所设起止姿态。

## 工程结构

`apps/desktop` 是 C# WPF/WebView2 宿主；`apps/ui` 是 React/TypeScript/Three.js；`python/src/satellite_studio` 包含领域数学、任务、网页采集桥接和数据校验；`schemas` 保存协议；`tests` 和 `tools` 用于构建验收。`KIMI/` 是独立工作空间，由 Git 忽略，不参与本项目构建或审查。

所有运行库、编译产物、日志和生成数据进入 `var/`。购买的模型、转换二进制和本地依赖不进入 Git；仓库保留源码、模型清单和文本配方。仅下载 Git 源码需要自行准备授权模型和开发环境。

## 版本留存

同级 `SatelliteDatasetStudio-V1` 保存修改前完整工程、安装包和历史数据；原始 `SatelliteDatasetStudio` 也保持原位。V2 不含旧协议兼容或迁移入口。目录划分见 [版本说明](docs/version-layout.md)。

## 构建与验证

Python 3.11+、Node.js 24、.NET 8，依赖以锁文件为准。Node.js 用于开发构建与测试，正式网页采集复用工作台 WebView2，无需额外浏览器进程或 Node.js 运行时。离线模型制作工具仍可独立使用 Blender 转换素材，不是应用运行依赖；购买素材、旧版本和本机 Blender 安装均保留。

```powershell
python -m pip install -e ./python
pnpm --dir apps/ui install --frozen-lockfile
pnpm --dir apps/ui run test
pnpm --dir apps/ui run build
./tools/test-python.ps1
./tools/build-desktop.ps1
```

开发脚本读取 `var/runtime.json` 的 Python 路径或 `SATELLITE_PYTHON`，遗留 Blender 配置不再参与运行；安装版使用内置运行时。GLB-only 应用打包见 [离线发行](packaging/README.md)。

## 后续开发约定

开发阶段直接修改V2源码并更新可运行开发构建，使用tools/start-desktop.cmd检查功能。按用户2026-11-01指示，不在每轮修改后自动压缩或制作安装包；待功能稳定、用户需要发行时再统一打包。历史V2.0包留在var/releases，不作为后续修改的必经步骤。
