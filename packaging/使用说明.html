WINDOWS 离线版 · 0.1.0

Satellite Dataset Studio
使用说明

选择模型和采集方式，由软件生成卫星图像与对应标签。无需手动旋转后截屏，也无需单独打开 Blender。

安装启动三种采集数据位置任务管理升级卸载

1. 安装与启动

  1. 在 Windows 10 或更新版本的 x64 电脑上运行安装包。此版本不适用于 32 位 Windows 或 ARM64 系统。
  2. 按向导安装，可选择创建桌面快捷方式。安装面向当前用户，不需要管理员权限。
  3. 从开始菜单打开 Satellite Dataset Studio，等待右上方显示“本机服务已连接”。

安装包附带 .NET、Python、Blender、固定版本 WebView2 和所需本地资源。无需另装开发工具、插件或依赖，也无需购买附带运行时。安装和首次启动不下载依赖。

默认程序目录：%LOCALAPPDATA%\Programs\SatelliteDatasetStudio。

当前安装包尚未使用发行者证书签名，Windows 可能提示“未知发布者”。请核对来源与随包 SHA256；不要关闭系统防护来安装来源不明的文件。正式渲染需要兼容 Blender Eevee 的显卡和驱动。

2. 三种采集方式

左侧选择模型与采集模式；右侧设置姿态、目标距离、太阳光照和噪声。中间下方“正式图像”查看已保存的结果，“最近任务”查看进度。

方式操作生成内容
单张采集选择模型，调整右侧参数，点击“生成当前单帧”。当前姿态和距离的一帧。此按钮始终只生成一帧。
全姿态采样左侧选“全姿态采样”，填写数量和种子，再点“开始生成”。合法三维随机姿态；距离在 10–30 km 分层采样。
连续序列左侧选“连续序列”，填写数量和种子，再点“开始生成”。逐帧连续旋转，距离从 30 km 变化到 10 km。当前默认每秒一帧、每秒旋转 1°。
推荐先试拍，再小批量。先生成当前单帧，查看“干净图像”和“含噪声”；再生成 30 帧小样，检查不同姿态、距离的效果，满意后扩大数量。

先选模式再填写数量，切换模式会恢复初始数量。全姿态采样和连续序列自动生成姿态与距离，不使用右侧手动值；模型、光照、噪声与种子仍参与任务。同一任务的光照和噪声参数保持固定。

一个任务只采集一个模型。要生成多个模型的数据，请分别选择并提交；队列按提交顺序处理。可以在上一任务运行时配置下一任务，已提交任务的参数不会被后续操作改变。

“自由观察”中的拖动与缩放仅改变查看位置，不改变采集姿态或距离。彩色观察预览有展示补光，实时视口不是最终文件；请以“正式图像”中保存的 PNG 判断质量。坐标轴和辅助线不会进入正式图像。

默认高斯噪声 σ=0.012、泊松峰值=96。关闭噪声时仍输出干净与含噪两个目录，对应图像像素相同。相同模式、数量、模型、参数和种子可复现采样设置及噪声随机过程；不同显卡或渲染器版本不承诺逐像素完全一致。

3. 数据保存在哪里

安装版默认工作目录：

%LOCALAPPDATA%\SatelliteDatasetStudio\workspace

任务输出位于：

%LOCALAPPDATA%\SatelliteDatasetStudio\workspace\jobs\<任务ID>\

将路径粘贴到资源管理器地址栏即可进入。“正式图像”区域也显示所选任务的实际路径；当前界面没有整批 ZIP 下载或目录选择按钮。

<任务ID>/
├─ job.json               任务参数快照
├─ images_clean/         干净 PNG
├─ images_noisy/         同帧含噪 PNG
├─ labels/               同名 YOLO 检测框 TXT
├─ poses/                同名姿态 JSON
└─ coverage.json         仅全姿态采样完整结束后生成

正式图片固定为 1024×1024、8 位灰度 PNG。1000 帧包含 1000 个姿态样本、2000 张配对 PNG。YOLO 检测类别目前统一为 0；模型 ID、六角、四元数、距离与相机信息保存在姿态 JSON 中。六角单位为弧度，无定义角度带有效性标记。

备份整个任务目录。不同任务都从 000001 编号，不要将同名文件混放而覆盖数据。软件不会自动划分训练集与验证集。

4. 进度、取消与关闭

在“最近任务”中选择任务，查看状态、完成帧数及错误。列表最多显示最近 8 个任务，更早的文件不会因此删除。“正式图像”显示所选任务最近完成的一帧；检查整批请进入输出目录。

  • 参数设置错误时取消原任务，再提交新任务；不能直接修改已提交任务。
  • 取消可能需要等待当前帧结束，已经完整生成的帧保留。
  • 关闭桌面软件会停止它启动的后台进程。下次启动时，先前运行中的任务标为“已中断”，不会自动续跑；等待中的任务继续排队。
  • 当前没有暂停或从第 N 帧续跑的按钮。长批量期间保持软件运行，避免电脑睡眠。

生成速度取决于电脑。先用小批次测量耗时与空间占用，第一帧可能包含启动开销。失败时查看界面错误和工作目录 logs/ 中的日志。

5. 升级与卸载

升级前等待采集完成并退出软件。安装器会检查占用文件，不使用强制结束选项，也不自动重启应用。不要在长批量运行时升级。

从 Windows“已安装的应用”卸载，会移除程序与快捷方式，保留独立工作目录中的数据、任务记录和日志。清理这些数据前请先备份。

固定 WebView2 所需的读取和执行权限只设置在本应用 runtime\webview2 目录，不修改全局权限。失败时安装器显示具体原因；请保留安装日志，不要给整个用户目录或磁盘放宽权限。

这是本地离线说明，不使用远程脚本、字体或图片。运行时来源、版本和许可证见安装目录 licenses/，文件清单见 release-manifest.json。

本机安装与功能验证由发行流程记录；全新 Windows 虚拟机、未预装依赖且断网的完整验收仍待完成。新电脑的显卡与驱动兼容性需以实际结果为准。
