# V2.1 验证记录

日期：2026-11-01。范围为反馈第三条方案 A：自定义起止姿态、包含首尾的帧数、过渡预览及批量采集。显示版本 V2.1，程序版本 2.1.0；数据协议仍为 satellite-pose-4.0 / lh-client-world-v2。

## 已实现范围

新增“自定义姿态序列”，默认起点 0°、终点 X90°、120 帧。支持记录当前手动姿态为端点，播放、暂停、逐帧预览和退出预览。预览独立于手动姿态和端点配置；预览中的“生成当前单帧”保存实际显示的姿态。整批使用提交时的参数快照，距离、相机、光照与噪声配置固定。

起止姿态用四元数沿最短路径插值，首尾均包含。相同姿态及 q/-q 得到静止序列；精确半圈采用前后端一致的确定性方向规则。本轮不包含整圈、多圈、指定旋转方向或鼠标轨迹录制。

原 V2 的单张、全姿态采样、随机连续序列和工作区继续使用。V1 归档及原始工程未修改。

真实 WPF/WebView2 操作验证端点记录、播放暂停、手动姿态恢复、空值拒绝、极大角输入和逐帧预览。三帧序列中间帧显示 X45°，点击单帧后请求与正式 JSON 也为 X45°；提交整批后修改终点和距离，仍输出原来的 0°、X45°、X90° 和 20 km。无页面异常、无资源请求失败；关闭窗口后自有后台服务退出。证据：var/verification/v2.1-desktop/report.json 及其中记录目录的截图与数据。

## 验证边界

本轮在当前 Windows 电脑、现有六模型资产和本地运行库上验证，未进行全新电脑、其他显卡或十万帧长时间运行验收。Three.js 预览与 Blender 正式出图的光照和材质存在近似差异，以保存 PNG 为准。JSON Schema 已解析并检查关键约束与运行时一致性，未使用第三方完整 Schema 引擎验收。

按用户要求，本轮仅更新源码与可运行开发构建，不制作、压缩或安装 V2.1 安装包。var 下的运行数据、日志、截图与模型二进制不上传 Git。
