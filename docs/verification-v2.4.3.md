## 本轮修改

1. 单张与起止姿态序列中的“自由观察”改为“拖动调姿”。固定观察相机方向，鼠标左键拖动旋转卫星本身，右侧XYZ与四元数实时更新，正式单张采集使用同一姿态。
2. 数值输入与拖动双向衔接，XYZ读数显示到两位小数，内部四元数保持精度。起止序列可以把拖动后的姿态存为端点；播放和逐帧预览显示当前帧姿态，期间锁定编辑。
3. 滚轮只改变查看倍率，不改变拍摄距离。“复位观察”恢复倍率，“归零”恢复卫星姿态。自动采样与连续序列仍由原种子和算法生成姿态，不引入手动姿态覆盖。
4. 左侧展示区向下延伸；输出摘要、重置与生成按钮固定在右栏底部，拍摄参数独立滚动。
