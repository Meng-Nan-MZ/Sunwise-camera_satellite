# V2.4.5 验证记录

日期：2026-11-02。源码基线 `4f6a628` / `v2.4.4`。本次更新源码与可运行开发版，不制作安装包或压缩包。

## 修改范围

1. 模型标题、视角切换、预览辅助和状态合并为一行。长标题省略并保留完整悬停提示；预览栏宽度不超过680逻辑像素时，辅助操作收进“预览辅助”。
2. 删除安全框，新增默认关闭的“旋转预览”。在彩色的拖动调姿/模型预览中，绕竖直轴以12°/s旋转，从上方看为逆时针。只修改视口对象的临时显示变换，不改变XYZ、距离、关键帧或正式采集。
3. 关闭旋转、切换拍摄视角/模型/采集方式/页面、手动编辑姿态时停止旋转并恢复设定姿态；手动拖动接着编辑设定姿态。起止序列处于播放、暂停或逐帧预览时禁用旋转，避免两种运动叠加。滚轮调距仍沿用V2.4.4的物理距离联动。
4. 显示名称统一为“随机姿态批量”“自动旋转序列”“起止姿态序列”；内部模式标识与采集算法保持不变。
5. 底部改为14像素高的细线与小卫星装饰，原本地保存、提交冻结和结果说明移至设置的“使用说明”。
