# V2.4.2 验证记录

日期：2026-11-02。源码基线为 `5799048` / `v2.4.1`。本轮提供源码和可运行开发版，没有制作安装包或压缩包。

## 本轮修改

1. 桌面“更改”直接打开系统文件夹选择器，选定后自动保存；取消不写设置，保存失败保留已生效位置并允许重试。设置页提供恢复默认及折叠的保存位置说明。纯浏览器保留路径输入与保存回退。
2. 采集和追加噪声共用无、轻微、中等、自定义四档。轻微为高斯 σ=0.006、泊松峰值256；中等沿用原数值0.012、96。只有自定义显示专业数值，关闭噪声保留草稿值。
3. 随机种子放在“更多参数”，无噪声时仍可配置采样种子；只读四元数、坐标与输出约定收进“技术详情”。追加噪声与采集草稿相互独立。
4. 删除品牌下英文、自由观察英文及旧保存面板装饰标题。
5. 翻帧等小工具点击区域至少34逻辑像素。
6. 结果列表和详情区改用分隔线、留白及选中标记，减少嵌套边框。

## 审查修复与证据边界

独立审查发现：设置页关闭时，如果目录已经选定但服务器尚在保存，组件卸载可能使界面提前停止等待。已将“用户选定后”的保存归交由共享控制器管理，持续禁止提交新任务直到保存确认；选定前关闭仍取消选择。延迟保存、关闭设置页、选择取消和应用释放测试均通过，最终审查无剩余阻塞问题。

首轮验收通过后，最终构建的一次验收遇到只读HTTP连接传输失败；失败报告保留在 `1793551205358-83364/`。脚本改为关闭短连接，并仅对GET的连接异常允许一次记录明确原因的重试，不重试写请求或产品错误。最终运行工作期间无传输重试，报告的两次ECONNREFUSED均为关闭自有服务后的健康探测。

协议、坐标数学、模型、噪声算法和正式渲染配置沿用原版本；本轮只增加预设映射和界面操作调整。`KIMI/` 继续忽略，未读取、修改或提交。未对其他显卡、全新Windows或安装包作验证承诺。
