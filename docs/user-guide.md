# 使用指南：单张与批量采集

适用于 2026-09-20 核对的当前重构版界面。软件按任务生成图片和标签，不需要手动旋转模型再截屏。

## 启动和界面

安装版从开始菜单或桌面的 Satellite Dataset Studio 快捷方式打开，等待右上方显示“本机服务已连接”。不必手动打开 Blender；第一次正式生成时软件会启动包内的后台渲染器。开发目录也可双击 `tools/start-desktop.cmd`。

- 左侧：选择模型，选择采集模式，填写数量和随机种子，点击“开始生成”。
- 中间上方：三维预览。“自由观察”可拖动、缩放；“拍摄视角”显示采集相机构图。
- 右侧：目标姿态、距离、太阳光照和像素噪声。
- 中间下方：“正式图像”查看已保存的结果；“最近任务”选择任务、查看进度和状态。

自由观察的鼠标拖动、滚轮缩放只改变观察位置，不改变采集姿态和距离。手动采集姿态由右侧 X/Y/Z 旋转控制，距离由右侧“目标距离”控制。这里三个旋转滑块是欧拉角，不是需求中的六个 α/β 角；六角会自动计算并保存到姿态 JSON。

当前自由观察有彩色材质和独立补光，拍摄预览为灰度且采用另一套光照。判断数据质量应查看“正式图像”中保存的 PNG；实时视口不是最终文件。坐标轴和安全边界不会进入正式输出。

## 三种采集模式

| 模式 | 姿态与距离 | 数量 | 用途 |
| --- | --- | --- | --- |
| 单张采集 | 使用右侧当前姿态、当前距离 | 1 帧 | 检查材质、光照和噪声 |
| 全姿态采样 | 随机生成合法三维姿态；距离在 10–30 km 分层随机采样 | 用户填写，初始为 1000 | 收集不同朝向的独立样本 |
| 连续序列 | 种子生成初始姿态及旋转轴，逐帧连续旋转；距离从 30 km 变到 10 km | 用户填写，初始为 120 | 收集连续变化、可用于跟踪的图像序列 |

全姿态采样和连续序列均不使用右侧手动设置的姿态、距离作为拍摄值。光照、噪声、所选模型和种子仍参与任务；同一任务的光照和噪声参数保持固定，不自动随机化太阳方向。

连续序列当前界面使用默认设置：1 秒一帧、1°/秒。120 帧的模拟时间戳为 0–119 秒，帧间约转 1°。模拟秒数不代表电脑生成图片所用的时间。这些速度、间隔和距离端点目前没有界面编辑入口。

先选择模式，再填写数量；切换模式会恢复该模式的初始数量。批量数量允许 1–100000，首次使用建议先生成 30 帧小样。

## 第一次批量采集：先确认正式效果

1. 左侧选一个模型，例如 GPS 导航卫星。
2. 右侧把姿态“归零”、距离设为 20 km，先保持默认太阳光：方位角 35°、高度角 28°、光照能量 4。这只是试拍起点，不保证任意模型和姿态都有相同亮度。
3. 在“正式图像”区域点击“生成当前单帧”。此按钮始终只生成当前一帧，即使左侧选择了批量模式。
4. 查看已保存的正式 PNG，切换“干净图像”和“含噪声”。过暗时先检查太阳方向和姿态；不要只把光照能量一直加大。必要时调整后重新生成单帧。
5. 左侧选择“全姿态采样”，数量填 30，随机种子例如 20260920，再点击左侧“开始生成”。
6. 等待完成，进入输出目录检查若干不同姿态和距离的图片。单张试拍只能证明该姿态的效果，不能代替批量小样检查。
7. 小样满意后，把数量改为 1000，再点“开始生成”，生成独立的新任务。

一帧包含干净、带噪两张对应图像。因此 1000 帧是 1000 个姿态样本、2000 个 PNG，并非 2000 个独立姿态。

## 噪声和随机种子

- 默认噪声为高斯 σ=0.012、泊松峰值=96。
- 高斯 σ 越大，高斯噪声越明显；同样亮度下，泊松峰值越小，相对泊松噪声越明显。
- 无论是否开启噪声，都保留两个图像目录；关闭噪声时两者像素相同。
- 相同模式、数量、模型、参数和种子可复现采样设置及噪声随机过程。不同显卡或渲染器版本不承诺逐像素完全一致。
- 只想再获取一批新的随机姿态，可更换种子；完全重复参数与种子会产生重复采样。改变数量后，同一种子也不意味着较小任务是较大任务的前缀。

## 六个模型分别批量采集

当前一个任务只采集一个模型，不会自动遍历模型库。可以选择模型 A、设置数量和种子、提交；随后选择模型 B 再提交，依次类推。任务按提交顺序串行生成。

例如六个模型各提交 1000 帧，就是六个任务、6000 帧样本，合计 12000 个 PNG。可以在上一任务运行时配置并提交下一任务；已提交任务使用冻结参数，不会因后续切换模型、调整面板而变化。

每批的太阳方向、光照能量和噪声参数固定。若要增加光照多样性，需要改变太阳参数后另建任务。若为了比较光照变化而保留相同姿态，可在相同模式和数量下保留同一种子。

## 输出在哪里

安装版默认目录为（可直接复制到资源管理器地址栏）：

```text
%LOCALAPPDATA%\SatelliteDatasetStudio\workspace\jobs\
```

每个任务在该目录下有独立的任务 ID 文件夹。开发脚本默认写入工程的 `var/workspace/jobs/`。“正式图像”区域会显示所选任务的实际输出路径；如果启动时另选了工作目录，以界面显示的路径为准。当前界面没有整批 ZIP 下载或目录选择按钮。

```text
<任务ID>/
├─ job.json                   # 任务参数快照
├─ images_clean/
│  ├─ 000001.png              # 不含模拟像素噪声
│  └─ ...
├─ images_noisy/
│  ├─ 000001.png              # 相同帧的带噪版本
│  └─ ...
├─ labels/
│  ├─ 000001.txt              # YOLO检测框
│  └─ ...
├─ poses/
│  ├─ 000001.json             # 六角、四元数、距离、相机和来源信息
│  └─ ...
└─ coverage.json              # 仅全姿态采样完整结束后生成
```

同一帧四种文件使用相同编号。所有正式图片固定为 1024×1024、8 位灰度 PNG。预览中的辅助线不进入图片。

YOLO TXT 保存类别和归一化检测框；当前六个模型的检测类别都是 `0`，没有自动分成六个类别。具体模型 ID 与姿态信息在对应 JSON 中；六角单位为弧度，角度无定义时带有有效性标记。软件不会自动生成训练/验证划分或训练所需的完整配置。

不同任务都从 `000001` 编号。备份或交付时保留任务目录和内部配对关系，避免把多批文件直接复制进同一个目录而覆盖同名文件。“正式图像”显示所选任务最近完成的一帧；查看整批应进入输出目录。

## 进度、取消与关闭

在“最近任务”中选中任务，可看到等待、生成中、已完成、失败、已取消或已中断，以及已完成帧数/总帧数。“最近任务”列表最多展示最近 8 个任务，不代表更早文件被删除。

已入队任务不能在原任务上改参数。若设置错误，取消该任务，再用新参数提交。取消可能需要等待正在渲染的帧结束；先前已完整发布的帧保留，取消期间正在处理的帧可能不被计入完成数。

当前没有暂停和从第 N 帧恢复的按钮。关闭桌面软件会停止它启动的后台进程；再次打开时，之前运行中的任务标为“已中断”，不会接着生成。仍处于等待状态的任务会在服务重新启动后继续排队执行。

长批量期间保持软件运行并避免电脑睡眠。先用小批次测量实际耗时和磁盘占用，再估算大批次；首次渲染有启动开销，不能只用第一帧耗时估计所有帧。任务失败时查看界面错误和工作目录 `logs/` 中的日志。
