# Satellite Dataset Studio V2.4.4 使用指南

## 开始采集

双击tools/start-desktop.cmd。默认窗口约1120×680逻辑像素，按屏幕工作区与缩放自动收紧，可以继续拖动或调整大小。默认深色，“设置”中可切换浅色，选择会保存在当前工作区。

“数据采集”页顶部选择模型、采集方式与输出位置。左侧是三维预览，右侧为拍摄设置，可展开光照与噪声、更多参数及技术详情，右栏底部固定提供输出摘要、重置和生成按钮，参数可在上方滚动，左侧展示区延伸到下沿。

1. 单张采集：配置卫星朝向与距离，生成一张图像。
2. 全姿态采样：均匀采样SO(3)姿态，可以固定距离或选择10–30 km分层自动变距。
3. 连续序列：从种子生成随机初始姿态与旋转轴，默认1°/s、1秒间隔；可固定距离或按原规则从30 km到10 km变化。
4. 起止姿态序列：指定起点、终点和至少两帧，包含首尾并沿最短路径插值；整批相机、距离与光照固定。

四种方式默认使用固定20 km拍摄距离，可输入10–30 km、拖动滑杆或在三维预览中滚动滚轮。滚轮向上靠近、向下远离，右侧距离数值实时同步；确认输入或拖动滑杆也会改变预览构图。显示最多保留两位小数，内部保留完整精度，正式出图使用同一距离。输入完成后按Enter或离开输入框提交数值，超出范围按控件边界处理。

全姿态和连续序列的“拍摄距离方式”可改为自动；此时不显示固定距离输入，预览会注明距离仅供参考，滚轮调距与“重置距离”禁用，不改变自动采样策略。

“拍摄视角”检查正式采集构图；单张和起止序列可切换“拖动调姿”，用鼠标左键或单指拖动旋转卫星，右侧XYZ实时同步；直接输入角度也会更新卫星。两种视角的相机方向、拍摄距离和视场一致，拖动调姿保留彩色材质与观察补光。单张采集使用当前姿态和距离。坐标轴、安全框、“重置距离”直接放在预览工具栏，辅助线不会进入正式PNG。“重置距离”恢复20 km，保持当前卫星姿态；“归零”单独恢复卫星零姿态。

起止序列可拖动到期望姿态，再点击起点或终点的“使用当前姿态”。播放或逐帧预览时显示当前帧姿态并锁定姿态编辑，仍可调整整段固定拍摄距离，端点姿态保持不变；退出预览后恢复手动调姿。全姿态和连续序列按原种子生成姿态，其模型预览不提供手动调姿；选择固定距离时仍可用滚轮调距。XYZ显示保留两位小数，内部四元数保持精度；接近±90°时等价欧拉表达可能变化，真实姿态保持连续。

右侧“光照与噪声”可展开详细设置；默认关闭噪声。“更多参数”可设置随机种子；只读四元数与坐标约定放在“技术详情”。提交后所有参数冻结，编辑草稿、重置或切换页面不改变已提交内容。

起止姿态预览不会覆盖端点，相同起止姿态得到静止序列；0°到360°不表示转满一圈，本版没有整圈、多圈或指定方向采集。

噪声提供“无／轻微／中等／自定义”：默认无噪声；轻微使用高斯标准差0.006、泊松峰值256；中等沿用0.012、96。只有自定义显示专业数值。这些是便捷的图像噪声预设，不代表相机传感器标定；最终任务仍记录实际参数和随机种子。

## 查看结果

“任务与结果”左侧可以搜索已加载任务，按模型或状态筛选，并加载较早记录。点击任务后，右侧显示该任务保存的真实图片与信息。使用上一帧/下一帧逐帧查看；原图和噪声图只按实际文件启用。

拖动、滚轮及缩放按钮只调整图像显示，不改动文件。打开图片可查看原PNG，打开所在文件夹可查看任务目录。图片读取失败时可“重新加载图像”。任务ID、实际路径和参数详情默认折叠，其数据来自保存记录而非当前采集草稿。

运行中任务可以取消，完整已保存帧保留；失败或中断显示原因。没有暂停或断点续跑。

## 追加噪声

选择已完成、原图完整的任务，点击“基于原图追加噪声”，在独立窗口选择噪声预设，或选“自定义”设置高斯、泊松参数；“更多参数”可设置种子，再生成新版本。选择“无”时不创建重复原图的追加版本。这些设置与数据采集草稿相互独立，不改变来源任务。

追加版本只保存images_noisy/、noise_meta/和job.json，复用来源原图、姿态与YOLO，不重复渲染或复制。再次基于噪声版本追加仍解析到原始采集来源。相同来源与相同参数/种子可复现结果。

## 保存位置与备份

桌面顶部“更改”直接打开系统文件夹选择器，选定后立即保存并提示“保存位置已更新”，无需再次应用。取消选择或保存失败时保留原位置，可重试；完整路径可通过悬停查看。“设置”中的“恢复默认”返回当前工作区的jobs/；目录关系可展开“保存位置帮助”。独立浏览器使用简单路径输入与“保存”作为回退。

支持中文、空格和其他磁盘，目录必须已存在且可写。不可用时明确报错并保留设置，不自动换盘。“打开文件夹”打开当前已应用位置，任务页“打开所在文件夹”打开该任务冻结的目录。

新采集使用提交时的保存位置；排队、运行和历史任务继续使用原路径。噪声版本始终放在来源旁边。数据库、设置和日志仍在程序工作区，这不是移动或导入数据的功能。

备份时同时保留工作区数据库与各数据集目录，保持原图和噪声版本同级。仅移动一个噪声目录不包含完整数据集。

## 输出与坐标

采集目录保存images_clean/000001.png、labels/000001.txt、poses/000001.json等逐帧文件；开启噪声时另存images_noisy/。图片为1024×1024、8位灰度，TXT为五列YOLO。

零姿态本体X向图像右、Y朝观测相机、Z向图像上。欧拉角采用这套左手系的内禀XYZ；对外四元数为{W,X,Y,Z}。Location.SatQuat表示目标本体系到世界系，Location.CamQuat表示正式观测相机系到世界系。

固定观测相机在世界(0,d,0)，朝目标，上方对齐世界Z，CamQuat为{W:0.5,X:0.5,Y:-0.5,Z:0.5}。改变目标姿态或距离不改变这个相机朝向。载荷相机另行记录，不能代替观测相机。K采用明确标注的CV像素投影基，使用JSON给出的转换或投影矩阵。

协议仍为satellite-pose-4.0。新任务额外记录距离策略；旧快照缺少该字段时按原模式规则解析，不补写、不重新解释。详见[接口与坐标](architecture/interfaces.md)。

## 运行与版本

新采集仅使用Three.js，不需要Blender、生产端Node.js或额外浏览器。沿用threejs-detail-v1，主题和预览辅助不改变正式图片。采集期间保持工作台打开；断开连接或图形上下文失效会明确结束当前尝试，完整帧保留，恢复后重新提交。

已完成的V2系列Blender任务可查看并基于已有原图追加噪声；新版不执行旧Blender采集。V1数据继续用V1查看，不把V1工作区交给V2。

开发版工作区为工程var/workspace/，安装版为%LOCALAPPDATA%\SatelliteDatasetStudioV2\workspace。本轮只更新可运行开发版，没有新安装包。旧包、离线制作工具和原始资产保留。
