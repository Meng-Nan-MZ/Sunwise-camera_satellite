# Satellite Dataset Studio V2 使用指南

## 开始使用

打开带 V2 标识的程序。左侧选模型和采集模式，中间检查预览，右侧调整目标姿态、距离、光照和噪声。

零姿态时：红色 X 轴向右，绿色 Y 轴朝观测相机，蓝色 Z 轴向上。转动卫星时，本体轴随卫星一起转。右侧使用这套左手系的内禀 XYZ 旋转角；显示的四元数按 W、X、Y、Z 排列。

自由观察只改变查看位置，不改变正式采集相机或卫星姿态。拍摄视角使用固定采集构图；正式效果以已保存 PNG 为准。坐标轴、安全框不会进入正式图片。

## 采集方式

1. 单张：使用右侧当前姿态和距离。点击“生成当前单帧”。
2. 全姿态采样：生成合法 SO(3) 随机姿态，距离在 10–30 km 内分层采样；右侧手动姿态不作为批量姿态。
3. 连续序列：从随机姿态和轴出发连续旋转，默认 120 帧、步长 1 秒、角速度 1°/s，距离从 30 km 到 10 km。

本轮尚未增加自定义姿态轨迹。随机种子用于复现采样；提交时冻结参数，之后修改面板不影响已提交任务。当前任务串行执行，可取消，完整帧保留；没有暂停或断点续跑。

## 输出

每任务独立目录，帧从 `000001` 编号，保存 `images_clean/`、`images_noisy/`、`labels/`、`poses/`。正式 PNG 为 1024×1024 灰度。当前噪声开关关闭时仍保存配对副本；噪声解耦属于后续反馈，本轮不改。

JSON 的 `Location.SatQuat` 表示目标本体系到世界系，`Location.CamQuat` 表示生成当前正式图片的观测相机系到世界系；两者均为 `{W,X,Y,Z}`。

默认观测相机位于世界 `(0,d,0)`，朝向目标，上方对齐世界 Z，因此 CamQuat 固定为 `{W:0.5,X:0.5,Y:-0.5,Z:0.5}`。只改变距离或卫星朝向不改变这个相机四元数。

卫星载荷相机是另一个对象，与观测相机分开记录。附属元数据中的相机 K 使用明确标注的 CV 像素投影基，不应直接套到“X上/Y左”的相机坐标；使用随 JSON 给出的转换或投影矩阵。

## 保存位置与版本

安装版：`%LOCALAPPDATA%\SatelliteDatasetStudioV2\workspace\jobs`。开发版：工程 `var/workspace/jobs`。任务面板显示实际输出路径。

V2 从空任务目录开始，不读取 V1 的旧任务。历史图片和标签使用 V1 查看。切勿将新旧数据混合后仅靠改字段名作为同一协议使用。
