# Satellite Dataset Studio V2.2 使用指南

## 开始使用

打开带 V2.2 标识的开发程序。左侧选模型和采集模式，中间检查预览，右侧调整目标姿态、距离、光照和噪声。

零姿态时：红色 X 轴向右，绿色 Y 轴朝观测相机，蓝色 Z 轴向上。转动卫星时，本体轴随卫星一起转。右侧使用这套左手系的内禀 XYZ 旋转角；显示的四元数按 W、X、Y、Z 排列。

自由观察只改变查看位置，不改变正式采集相机或卫星姿态。拍摄视角使用固定采集构图；正式效果以已保存 PNG 为准。坐标轴、安全框不会进入正式图片。

## 采集方式

1. 单张：使用右侧当前姿态和距离。点击“生成当前单帧”。
2. 全姿态采样：生成合法 SO(3) 随机姿态，距离在 10–30 km 内分层采样；右侧手动姿态不作为批量姿态。
3. 连续序列：从随机姿态和轴出发连续旋转，默认 120 帧、步长 1 秒、角速度 1°/s，距离从 30 km 到 10 km。

4. 自定义姿态序列：指定起点、终点和帧数，按最短旋转路径生成包含首尾的序列。距离和光照采用当前面板设置，在整批内固定。

随机种子用于复现随机采样及噪声；自定义姿态不依赖种子。提交时冻结参数，之后修改面板不影响已提交任务。当前任务串行执行，可取消，完整帧保留；没有暂停或断点续跑。

## 自定义姿态序列

1. 左侧选择模型，再选择“自定义姿态序列”。
2. 右侧配置起始与结束XYZ姿态，或将当前手动姿态记录为某个端点。
3. 设置帧数，最少2帧且包含首尾；默认120帧。
4. 播放、暂停或拖动预览帧查看过渡，退出预览可恢复手动姿态。
5. 点击“开始生成”提交完整序列。播放进度不会改变已设定的起点或终点。

预览中的“生成当前单帧”会暂停并冻结实际显示姿态，只提交这一帧。自由观察仍只改变观察位置，不改变采集相机。

起止姿态相同会保持静止；本版本不提供整圈、多圈或指定旋转方向。即使欧拉角写成0°和360°，它们仍是同一姿态。

## 输出

每次拍摄任务独立目录，帧从 `000001` 编号，保存 `images_clean/`、`labels/`、`poses/`；开启噪声时再保存 `images_noisy/`。正式 PNG 为 1024×1024 灰度。关闭噪声时仅保存原图，结果区的含噪声切换不可用。历史 V2/V2.1 已保存的配对文件仍可查看，不会自动清理。

JSON 的 `Location.SatQuat` 表示目标本体系到世界系，`Location.CamQuat` 表示生成当前正式图片的观测相机系到世界系；两者均为 `{W,X,Y,Z}`。

默认观测相机位于世界 `(0,d,0)`，朝向目标，上方对齐世界 Z，因此 CamQuat 固定为 `{W:0.5,X:0.5,Y:-0.5,Z:0.5}`。只改变距离或卫星朝向不改变这个相机四元数。

卫星载荷相机是另一个对象，与观测相机分开记录。附属元数据中的相机 K 使用明确标注的 CV 像素投影基，不应直接套到“X上/Y左”的相机坐标；使用随 JSON 给出的转换或投影矩阵。

## 保存位置与版本

安装版：`%LOCALAPPDATA%\SatelliteDatasetStudioV2\workspace\jobs`。开发版：工程 `var/workspace/jobs`。任务面板显示实际输出路径。

V2.2 继续使用现有V2工作区，原V2/V2.1任务可继续查看；不读取V1的旧协议任务。V1历史图片和标签使用V1查看。切勿将新旧数据混合后仅靠改字段名作为同一协议使用。

## 基于原图追加噪声

1. 在“最近任务”中选中已完成的任务，确认其原图仍完整保留。
2. 开启右侧“像素噪声”，调整高斯与泊松参数，并在左侧设置随机种子。
3. 在正式图像区域点击“基于原图生成噪声版本”。此操作只使用所选任务的原图，以及当前噪声设置和种子；当前模型、姿态、距离、光照与帧数不参与计算。
4. 新任务完成后切换“含噪声/干净图像”比较。再次修改噪声参数或种子即可生成下一组版本；来源始终指向同一套原始图像。

追加噪声不调用 Blender；即使 Blender 不可用，仍能处理已有完整任务。原有取消与中断规则继续适用，取消会保留已完成帧。

每组追加版本只保存 `images_noisy/`、`noise_meta/` 和任务清单 `job.json`，复用来源任务的原图、姿态 JSON 和 YOLO。噪声元数据单独记录参数、种子、算法与来源文件摘要；来源姿态 JSON 中的噪声信息描述原始拍摄，追加版本以 `noise_meta` 为准。

移动、备份或交付这类数据时，应一起保留原始任务和噪声版本目录，并维持两者同级关系。单独移动噪声版本目录不包含完整数据集。
