# Satellite Dataset Studio V2.4 使用指南

## 生成数据

打开 V2.4 程序，在“生成数据”页上方选择卫星模型和生成模式。左侧检查真实三维模型，右侧配置本次参数，底部固定显示保存位置、任务摘要和生成按钮。“高级参数”内保留种子、详细光照/噪声与坐标说明。

零姿态的本体 X 向图像右、Y 朝观测相机、Z 向图像上，本体轴随卫星旋转。角度使用这套左手系的内禀 XYZ，四元数按 W、X、Y、Z 排列。

“模型观察”只改变观察相机，“采集构图”检查固定采集视角。观察缩放不改变正式姿态或距离，辅助轴和安全框不会进入 PNG。正式效果以保存图像为准。

1. 单张采集：使用当前姿态与距离，生成一张图像。
2. 全姿态采样：生成合法 SO(3) 随机姿态，距离在 10–30 km 内分层采样；手动姿态和距离不控制该批次。
3. 连续序列：从随机姿态和轴开始旋转，默认120帧、步长1秒、角速度1°/s，距离从30 km到10 km。手动端点不控制该模式。
4. 起止姿态序列：设置起始与结束 XYZ、至少两帧，包含首尾，沿最短路径插值；距离、相机和光照在同一批次内固定。

起止姿态可以从手动配置复制，播放或拖动时间轴预览不会覆盖端点。相同端点得到静止序列；0°到360°不会转满一圈，本版没有指定方向、整圈或多圈采集。

提交时冻结参数，之后编辑草稿、查看其他任务或切换页签不改变正在生成的内容。任务串行执行，可以取消，完整已保存帧保留；没有暂停或断点续跑。

## 任务与结果

选择任务查看保存时的模型、模式、进度、状态和实际输出位置。干净图与含噪声图按实际文件切换，没有噪声文件时不会复制或伪造图片。运行中任务可取消，失败和中断会显示原因。

对已完成且原图完整的任务，可调整噪声参数和种子生成新的噪声版本。此操作只使用来源原图与噪声设置，不使用生成页当前模型、姿态、光照、距离或帧数，不重复三维渲染。相同来源与相同参数/种子可复现结果。

追加版本只保存 images_noisy/、noise_meta/ 和 job.json；来源原图、姿态和标签保留原位。噪声元数据记录参数、种子、相对来源与摘要。再次基于噪声版本追加时仍解析到原始采集任务。

## 保存位置

底部点击“更改”，输入已有文件夹的完整路径，或使用系统“选择文件夹”，再点击“应用”。未应用的输入不改变实际位置，取消选择不更改路径。“恢复默认”返回当前工作区的 jobs/。

支持中文、空格和其他磁盘，重启后记忆选择。路径必须已存在且可写；不可用时明确报错并保留设置，不自动改存其他盘。系统窗口由桌面程序提供，独立浏览器仍可输入路径。

新采集在当前位置创建独立任务子目录；排队、运行中和历史任务继续使用提交时的位置。噪声版本始终放在来源旁边。数据库、设置和日志仍在工作区，这不是移动或导入数据的功能。

备份时同时保留工作区数据库与各数据集目录，维持原始任务和噪声版本同级关系。仅移动一个噪声目录不包含完整数据集。

## 输出与坐标

每个采集目录保存 images_clean/000001.png、labels/000001.txt、poses/000001.json 等逐帧文件；开启噪声时另存 images_noisy/。正式图为1024×1024、8位灰度，TXT为五列YOLO。

Location.SatQuat 表示目标本体系到世界系，Location.CamQuat 表示正式观测相机系到世界系，均为 {W,X,Y,Z}。固定观测相机位于世界(0,d,0)，朝目标、上方对齐世界Z，CamQuat为 {W:0.5,X:0.5,Y:-0.5,Z:0.5}。改变目标姿态或距离不改变此相机朝向。

载荷相机独立记录，不能代替观测相机。K采用明确标注的CV像素投影基，不能直接套到“X上/Y左”的相机坐标；请使用JSON给出的转换或投影矩阵。协议仍为 satellite-pose-4.0，见[接口与坐标](architecture/interfaces.md)。

## 渲染与历史

V2.4新采集只使用Three.js，启动和正式出图不需要Blender。沿用 threejs-detail-v1 配置；浅色主题不改变采集背景、灯光和正式PNG。网页采集期间保持工作台打开，断开连接或显卡上下文失效会明确结束当前尝试，完整帧保留；恢复后重新提交任务。

已完成的V2系列Blender任务保留原协议和后端定义，仍可查看及基于已有原图追加噪声，不自动改写或重新渲染。V2.4不执行旧Blender采集；需要新图时创建新的网页任务。V1数据继续用V1查看，不把V1工作区交给V2。

开发版默认工作区为工程var/workspace/；安装版为%LOCALAPPDATA%\SatelliteDatasetStudioV2\workspace。本轮不制作安装包，历史安装包不含V2.4功能。离线资产转换工具及Blender安装独立保留，供开发端制作模型，不参与软件日常运行。
