# Windows 离线安装说明

适用于 Satellite Dataset Studio 0.1.0 的 Windows x64 离线安装包。

## 安装与启动

1. 将 `SatelliteDatasetStudio-0.1.0-win-x64-setup.exe` 复制到 Windows 10 或更新版本的 x64 电脑。此版本不适用于 32 位 Windows 或 ARM64 系统。
2. 双击安装文件，按向导安装。安装仅面向当前 Windows 用户，不需要管理员权限，可以选择创建桌面快捷方式。
3. 从开始菜单打开“Satellite Dataset Studio”，等待界面显示“本机服务已连接”。同组的“使用说明”可以离线阅读。

安装包附带 .NET、Python、NumPy、Pillow、Blender、固定版本 WebView2、本地网页资源与模型。无需另装开发工具、浏览器插件或运行时，也无需购买这些附带运行时。安装和首次启动不下载依赖；程序通过本机回环地址与自己的后台服务通信。

默认程序目录：`%LOCALAPPDATA%\Programs\SatelliteDatasetStudio`。

当前安装包尚未使用发行者代码签名证书签名，Windows 可能提示“未知发布者”。请核对文件来源和随包 SHA256，不要为安装而关闭系统防护。来源或校验不符时停止安装。

正式渲染需要兼容 Blender Eevee 的显卡和驱动。首次生成会启动后台渲染器；请先生成小批次，确认效果和耗时。

## 三种采集方式

| 模式 | 操作 | 姿态与距离 |
| --- | --- | --- |
| 单张采集 | 选择模型，调整右侧姿态、距离、光照和噪声，点击“生成当前单帧” | 使用当前设置，只生成一帧 |
| 全姿态采样 | 左侧选“全姿态采样”，填写数量和种子，点击“开始生成” | 自动采样合法三维姿态及 10–30 km 距离 |
| 连续序列 | 左侧选“连续序列”，填写数量和种子，点击“开始生成” | 连续旋转，距离从 30 km 变化到 10 km；当前默认每秒一帧、每秒旋转 1° |

先试拍一帧，再生成 30 帧小样。查看“正式图像”中的干净与含噪图像，确认效果后再扩大数量。先选模式再填写数量，切换模式会恢复初始数量。

全姿态采样和连续序列不使用右侧手动姿态、距离作为拍摄值；所选模型、光照、噪声与种子仍参与任务。同一任务内光照和噪声参数固定。一个任务只采集一个模型；需要多个模型时分别提交，队列按顺序处理。

自由观察中的拖动与缩放只改变查看位置。彩色观察预览有展示补光，实时视口不是最终文件；以已保存的正式 PNG 判断质量。坐标轴和辅助线不会进入正式图像。

## 数据与日志

安装版默认工作目录独立于程序目录：

```text
%LOCALAPPDATA%\SatelliteDatasetStudio\workspace
```

任务默认输出目录：

```text
%LOCALAPPDATA%\SatelliteDatasetStudio\workspace\jobs\<任务ID>\
```

将包含 `%LOCALAPPDATA%` 的路径粘贴到资源管理器地址栏即可进入。“正式图像”区域也显示所选任务的实际路径。日志位于工作目录的 `logs/`。

- `images_clean/`：1024×1024、8 位灰度干净 PNG。
- `images_noisy/`：同帧含噪图像；关闭噪声时仍保留此目录，两版图像像素相同。
- `labels/`：同名 YOLO 检测框 TXT；当前检测类别统一为 `0`。
- `poses/`：同名姿态 JSON，包含六角、四元数、距离、相机和模型信息。
- `job.json`：参数快照；`coverage.json` 仅在全姿态采样完整结束后生成。

1000 帧是 1000 个姿态样本及 2000 张配对 PNG。不同任务均从 `000001` 编号；备份整个任务目录，避免混合文件而覆盖同名数据。软件不会自动划分训练集和验证集。

## 任务、升级与卸载

取消可能需要等待当前帧处理结束，已经完整生成的帧保留。关闭桌面软件会停止它启动的后台进程；重新打开后，之前运行中的任务标为“已中断”，不会从中断帧续跑。等待中的任务继续排队。当前没有暂停和断点续跑按钮。

升级前请等待采集完成并退出软件。安装器通过 Windows Restart Manager 检查文件占用，不使用强制结束选项，也不自动重启应用。不要在长批量运行时升级。

通过 Windows“已安装的应用”卸载，会移除程序和快捷方式，**保留独立工作目录中的数据、任务记录、日志和浏览器用户数据**。若要清理这些数据，请先备份，再自行处理工作目录。

安装器仅对自身 `runtime\webview2` 目录增加 Windows AppContainer 所需的读取和执行权限，不修改全局权限，也不授予写权限。失败时显示目录、返回码和工具输出，并阻止结束页启动应用；请保留安装日志排查。

## 版本与验证状态

运行时版本、来源和许可证位于安装目录 `licenses/`，文件清单及哈希位于 `release-manifest.json`。固定运行时不会在首次启动时自动联网更新；升级使用新的离线安装包。

安装器构建与本机安装结果由发行流程记录。**全新 Windows 虚拟机、未预装依赖且断网的完整验收仍待完成**；本机运行结果不能替代新机器及显卡、驱动组合的验证。详细操作参见开始菜单“使用说明”或同目录 `user-guide.md`。
