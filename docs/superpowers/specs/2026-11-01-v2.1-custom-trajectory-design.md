# V2.1 自定义姿态序列设计

用户已批准按甲方反馈第3条方案A实施，并明确本轮无需整圈/多圈、拖动录轨迹或安装包。测试通过后允许更新Git中的V2源码。

## 范围与方案

在现有SatelliteDatasetStudio-V2目录继续开发，软件显示V2.1，代码版本2.1.0，Git稳定标签v2.1。V1及原工程不修改，不再复制整套运行库。原有V2数据和三种采集模式继续可用，坐标协议仍为satellite-pose-4.0 / lh-client-world-v2。

采用“起止姿态+帧数”的独立custom_sequence模式。拖动轨迹记录、绕轴整圈及多圈、噪声解耦、目录选择、浅色主题均不在本轮范围。

## 接口与采样

新增POST /api/jobs请求：

```json
{
  "mode": "custom_sequence",
  "count": 120,
  "scene": {"model_id":"insat_3b","sat_quat":{"W":1,"X":0,"Y":0,"Z":0},"distance_m":20000},
  "trajectory": {
    "start_quat":{"W":1,"X":0,"Y":0,"Z":0},
    "end_quat":{"W":0.7071067811865476,"X":0.7071067811865476,"Y":0,"Z":0},
    "time_step_s":1
  }
}
```

- custom_sequence必须有trajectory.start_quat与end_quat，端点使用现有严格WXYZ校验并归一化；count为2..100000整数；time_step_s默认1，范围1e-6..3600。
- 其他模式不接受trajectory，避免静默忽略用户输入。原sequence参数继续服务随机连续模式；custom_sequence不接受sequence以免混淆两种轨迹。
- 请求快照持久化归一化端点与全部场景参数。sample_frames使用t=i/(count-1)，包含首尾；模型、距离、相机、光照、噪声设置在同一批内固定。随机种子仅影响噪声，不影响指定姿态。
- 内部使用单位四元数最短路径SLERP；先将终点符号与起点对齐，q与-q端点相同则静止。数值近重合时允许归一化线性极限。首尾精确返回归一化对齐端点，逐帧保持符号连续。
- 精确180°有两条等长路径：使用相对四元数最大绝对值轴分量为正的确定性选择，保证端点仅换符号不改变中间轨迹。该规则只是确定性约定，不提供用户指定旋转方向。
- frame_index从0开始，timestamp_s=i*time_step_s，sequence_id独立且稳定。每帧scene.sat_quat、Location.SatQuat、实际渲染姿态必须一致。
- 逐帧JSON新增trajectory元数据（type=shortest_path_slerp、start_quat、end_quat、time_step_s、count、t），保留WXYZ、左右手转换和相机精度校验；校验轨迹元数据与当前姿态的关系，禁止内容互相矛盾。
- 队列、取消、重启中断、参数冻结、文件命名和数据协议版本保持原规则，不改变Blender引擎边界。

## 界面与预览

新增“自定义姿态序列”选项和右侧独立配置区：起点/终点各有XYZ角度输入，可“使用当前姿态”记录当前手动姿态，并展示对应WXYZ；帧数默认120（包含首尾）。

用户可播放/暂停、拖动帧位置查看采样结果、退出预览。当前预览帧与四元数须清楚显示。预览不覆盖手动姿态或端点；退出后恢复手动姿态。预览时应避免手动控件与画面含义混淆：禁用手动姿态编辑或清楚区分手动配置与只读预览。修改端点/数量/模型时停止并重置预览，切换模式时退出预览。

预览帧使用与服务端一致的SLERP和共享测试向量；仅改变卫星姿态，观察相机行为保持原样。“开始生成”始终提交完整端点快照，不以播放进度代替起点。“生成当前单帧”使用当前实际显示的姿态；点击时冻结/暂停预览，防止画面继续移动造成误解。预览可不启动Blender。

界面明确提示“沿最短旋转路径过渡；相同起止姿态得到静止序列，不表示转一整圈”。不增加鼠标轨迹记录。

## 版本与验证

UI、Python包和桌面版本更新为2.1.0，标题V2.1；安装身份/工作区仍是V2，不为小版本另建空数据目录。后续打包模板可同步版本，但本轮仅构建开发程序，禁止压缩/安装/卸载操作。

TDD覆盖端点、中点、最短路径跨±180°、相同/相反表示、精确180°确定性、近重合、无效输入、最少两帧、快照冻结、旧V2任务重开、取消与真实图片/JSON一致。使用tests/fixtures/custom-trajectory-vectors.json作为双端数学标准；另有独立轴向和角距离断言，避免仅重复实现公式。

通过Python、UI、桌面回归、真实Blender自定义序列与桌面交互截图验收及独立审查后，普通提交并推送V2分支及v2.1标签，不强推，不上传模型/运行库/用户数据。
