# V2.4.4 拍摄距离双向联动

用户要求红框中的模型缩放和拍摄距离联动，延续V2.4.3调姿直接用于出图的交互。

## 方案

采用同一拍摄距离驱动预览和提交场景。滚轮改变物理距离，输入框和滑杆反向驱动预览；两种预览视角共用原拍摄相机投影与位置，材质、补光仍按视角切换。只更新数字而保留独立观察距离会产生两个状态，不能满足双向联动；按相对倍率映射旧观察相机虽改动少，但构图仍不同，故采用共用投影。这是基于既有代码的实现选择。

- 保留默认20 km和10–30 km边界；滚轮上滚拉近、下滚拉远，端点截断。
- 固定距离四种采集方式均可联动，两种预览视角都响应滚轮；自动变距不响应滚轮，不切换策略，显示说明。
- 起止序列预览可调整整段固定距离，卫星姿态仍按原规则只读；提交中的控件和滚轮暂停编辑，已提交快照冻结。
- 输入未按Enter即滚动时，先提交数字草稿；连续wheel用状态函数累计，不丢掉快速事件。滚轮不改变姿态。
- 原复位观察改为“距离归20 km”，只重置距离；自动变距时禁用。归零仍只改变姿态。
- 预览采用原固定短边视场，随画布宽高适配，不随距离自动调焦，不改模型尺寸或正式渲染配置。切换视角不会改变投影尺寸，颜色和光照允许不同。
- 距离显示最多两位小数，内部保留数值精度；更新所有“滚轮仅观察缩放”旧说明。
- 现有V2目录实施，版本2.4.4，验证/审查后普通提交与标签推送；不制作安装包、不读写KIMI，不改历史数据。
