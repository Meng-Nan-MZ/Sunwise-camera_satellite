# V2.4.3 拖动调姿与展示区增高

用户确认：拖动改变卫星姿态，右侧XYZ实时更新，并用于正式出图。上一张图要求将左下输出栏空间分配给卫星展示区。

## 方案与约束

当前自由观察只移动观察相机，不改变目标姿态。只显示相机角度不能满足已确认的出图要求；把移动相机后看到的角度直接写入目标会造成双重旋转。采用与拍摄相机同向的固定观察方向，拖动旋转卫星目标，统一更新客户端四元数和XYZ输入。

- 将“自由观察”改为“拖动调姿”，保留彩色材质与观察补光。鼠标左键/单指拖动修改姿态；右侧数值输入反向修改同一姿态。
- 滚轮是否联动拍摄距离单独询问；尚未回答时按保留现有仅观察缩放处理，不自动推断拍摄距离。复位观察只重置查看倍率；卫星归零独立。
- 单张采集使用拖动后的姿态。自定义起止序列可先拖动当前姿态，再设为起点/终点；播放或逐帧预览期间禁用姿态编辑，退出预览后恢复。
- 全姿态采样/连续序列由原种子与算法控制，界面明确提示不能手动调姿，不改变原采样算法。随机种子、光照、噪声不会因拖动改变。
- 数据采用既有左手系内禀XYZ与WXYZ协议，渲染边界仍为toRenderQuaternion；四元数作为准确状态，角度显示保留合理精度。接近万向锁时欧拉表达可能变化，但真实姿态连续。
- 拖出画布后仍完成当前手势；取消、失焦、切换模式/模型/重置后不能残留拖动；已提交任务快照不随后续拖动变化。
- 左展示区延伸到底部，输出简述及生成/重置按钮移到右侧固定底部，右侧参数独立滚动，小窗口尺寸保持。
