# V2.4.2 操作简化

用户在 V2.4.1 审查后明确选定六项修改；重复表格按同一需求处理，直接实施。

- 保存位置：桌面“更改”直接打开文件夹选择器，选定后调用现有保存接口，成功后显示新位置与“保存位置已更新”；取消和失败保留原位置。恢复默认仅在设置中，目录关系在帮助说明中。浏览器保留简单输入保存回退。
- 噪声：采集和追加窗口共享无、轻微、中等、自定义选项；仅自定义展开高斯与泊松参数。轻微采用 sigma=0.006、peak=256，中等沿用 sigma=0.012、peak=96；这些是界面便捷预设，不代表传感器标定。
- 分层：拍摄设置默认；光照与噪声、更多参数可展开；随机种子在更多参数中，四元数和协议为单独只读技术详情。
- 清除装饰英文；专业协议标识仅保留在技术详情。
- 小工具、翻帧、预览按钮至少 34px 高并保留清晰焦点。
- 结果列表减少逐项卡片边框，信息区用留白与分隔线；真实图片区域、选中状态与操作层级保持清楚。

延续用户要求：在现有 V2 目录和分支修改，版本 2.4.2；验证后正常提交推送，保留历史标签，不制作安装包，KIMI 保持忽略。不增加模型缩略图或改动采样、坐标、噪声算法、历史数据。
