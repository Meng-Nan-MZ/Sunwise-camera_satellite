# V2.2 原图与噪声图解耦设计

用户已要求执行此前路线中的 V2.2，对应甲方反馈第四条。保留 V2.1 自定义姿态及 V2 坐标协议，仍只交付源码和开发构建，验证后更新既有 V2 分支及 v2.2 标签，不制作安装包。

## 目标与选择

关闭噪声的新渲染任务只发布原图、标签和姿态 JSON；开启时仍发布原图与噪声图。选择已完成任务，使用当前噪声参数和种子生成追加版本，复用原图、YOLO 和姿态标签，不再启动 Blender。

考虑过覆盖原任务、完整复制数据集和独立噪声任务三种方式。覆盖会丢失可比较结果，完整复制违背节约空间的目的；本设计选择独立噪声任务引用原始任务。这是实现选择，用户授权的是功能范围。移动、备份时需同时保留来源任务，界面和文档说明此依赖。

不增加噪声算法、输出位置设置、主题、批量多档参数编辑、数据删除、独立打包导出或 V1 迁移。

## 数据与 API 合同

- 现有渲染 POST /api/jobs 不变；JobRequest 的四种模式不变。
- 新增 POST /api/jobs/{id}/noise-variants；请求只接受 `noise` 和 `seed`。noise 必须为对象且 enabled=true，sigma/peak 使用现有 Noise 范围及默认值；seed 必须显式为 0..4294967295 整数。不得接受 scene、count、mode、trajectory 等字段，以免界面暗中改变来源场景。
- 来源必须已 completed，且全部原图/姿态/标签已发布。完成的噪声版本可再次生成，解析至同一个原始渲染任务，禁止引用链。来源缺失、未完成或损坏应明确失败；不回退渲染。
- 新持久化任务 mode=`noise_variant`，count 取原始来源 total_frames。冻结规范来源 ID、noise、seed、count 与来源 DB 快照摘要，不修改原任务 snapshot、状态或输出。
- JobStore.request 返回 JobRequest 或独立 NoiseVariantRequest；追加任务沿用现有串行队列、逐帧发布、取消、中断恢复标记，不进入 sample_frames 或 renderer_factory。
- Job 响应新增 `source_job_id: string|null`、`noise`、`seed`、`can_generate_noise: boolean`、`latest_images: {clean:string|null,noisy:string|null}`。mode 对追加任务为 noise_variant；原有 latest_image_url 保留为可用图片的兼容字段。clean/noisy URL 依据完成帧 DB 文件白名单生成，不从字符串替换推测。

## 文件与可复现性

- 新 noise-off 正常帧的 files 省略 noisy，输出不创建 images_noisy 文件。历史 V2/V2.1 即使 noise.enabled=false，已声明并发布的配对副本仍可读、可校验，不删除旧文件。
- 姿态协议仍 satellite-pose-4.0 / lh-client-world-v2；pose.schema 的 files.noisy 改为可选，运行时启用噪声仍要求该文件。
- 原始任务验证复用完整姿态/标签/图像检查；支持直接验证已发布路径，不复制原文件到临时目录，也不写来源目录。
- 追加任务目录仅包含 job.json、images_noisy/{frame}.png、noise_meta/{frame}.json；不复制 images_clean、labels、poses。job.json 是持久化请求/依赖清单；source_job_id 对应同级任务目录。
- 每帧 noise_meta 使用独立 `satellite-noise-1.0` 协议，记录任务/帧 ID、来源任务/帧 ID、原图/标签/姿态的相对引用及 SHA256、输出 SHA256、噪声配置、master_seed、noise_seed、算法及实现版本。引用相对任务目录，工作区整体移动仍成立。
- 沿用 Poisson 后 Gaussian 像素噪声，提取共用函数，不改变当前算法。每帧种子沿用 frame_seed(seed, model_id, frame_id)，同原图、参数、种子生成相同像素。新增版本不引用旧噪声图。
- 每次只处理一帧，避免载入整套图片；来源内容改变或损坏在校验中明确失败。输出先 staging、完整解码/来源摘要/元数据检查，再文件发布与 DB 标记，未标记文件不可从 HTTP 读取。

## 界面

保留原有采集入口；结果区从 latest_images 显示真实可用的“干净图像/含噪声”。缺少噪声时默认原图并禁用噪声切换，说明未生成；历史配对图继续显示。

选中已完成任务后，“基于原图生成噪声版本”使用当前右侧噪声设置及随机种子。关闭噪声、无可用来源、请求进行中或参数非法时禁用并提示原因。此操作独立于 Blender 和模型预览就绪状态，绝不带入当前姿态、距离、光照、模型或帧数。成功后选择新任务，显示进度、来源、噪声参数/种子与原图复用说明；可取消，完整已发布帧保留。

程序/页面版本 V2.2，包版本 2.2.0，V2 AppId、工作区、坐标说明字符串保持一致。保存与校验变更需兼容既有 V2.1 快照。

## 验收

1. 四种渲染模式 noise-off 仅三类文件；noise-on 仍四类，文件声明与发布一致；历史 off 配对数据仍可读。
2. 使用会抛错的 renderer_factory 完成噪声任务，证明无 Blender；两组不同噪声、相同种子重跑、同源追加版本与规范来源解析正确；来源图像/姿态/标签和目录清单哈希不变。
3. 来源未完成/缺失/损坏、请求非法、取消与重启、临时文件访问、引用路径安全与产物篡改有真实行为测试。
4. 真实 Blender 生成至少三帧原图，关服务后在无 Blender 的 API/桌面环境追加两组噪声，验证 PNG、参数、种子、引用和来源哈希；界面切换/进度/取消/关闭清理通过。
5. 回归 Python、渲染、UI、桌面和打包工具测试，TypeScript/Vite/格式与开发构建，独立代码审查。后续打包脚本仅更新版本默认值，不执行安装包构建。
