# V2.3 Output Directory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Use this plan with its spec; root alone handles Git and native acceptance.

**Goal:** Let users choose and remember dataset storage while retaining access to existing tasks.

**Architecture:** The Python store remembers a preferred root and freezes each job's root. React applies it through bounded local API; WPF returns folders through a narrowly scoped correlated message. Noise variants stay with their canonical source.

**Tech Stack:** Existing Python/SQLite, React/TypeScript, .NET8 WPF/WebView2. No new runtime dependencies.

**Spec:** docs/superpowers/specs/2026-11-01-v2.3-output-directory-design.md
