# V2.1 Custom Trajectory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在V2.1支持指定起止姿态、预览与包含首尾帧的批量出图。
**Architecture:** 独立custom_sequence模式；纯四元数插值共享标准向量；现有任务、坐标和Blender链路复用。
**Tech Stack:** Python/NumPy、React/TypeScript/Three.js、C# WPF/WebView2、Blender。
**Spec:** ../specs/2026-11-01-v2.1-custom-trajectory-design.md

## Global Constraints

- 仅修改V2；保持已有V2任务、三模式、坐标协议与V1拒绝行为。
- 软件V2.1，包版本2.1.0，标签v2.1；本轮不制作安装包。
- API custom_sequence/count>=2/trajectory.start_quat/end_quat为WXYZ；固定距离和其他场景参数。
- 精确180°使用确定性相对轴选择；不实现整圈/多圈、鼠标轨迹或反馈4-6。
- 预览与生成使用相同数学标准；单帧抓取当前显示姿态。
- 测试与审查通过后更新已授权V2源码分支，保留历史。

## Review Focus

- q/-q、近重合、精确180°不产生翻转或长路；与共享标准及独立轴向断言一致。
- count2及最大数量惰性生成，timestamp和首尾无off-by-one。
- 修改表单或播放进度不污染提交快照/端点；单帧所见即所得。
- 新自定义任务取消/重启保持现有完整帧规则；旧V2任务继续读取。
- 小版本不清空工作区，不改变相机、噪声文件契约或资产。
