# V4 browser viewer implementation plan

**Goal:** Upgrade the existing browser-only satellite viewport with free observation, presets, display styles, fit, fullscreen, a collapsible model card, and one coherent toolbar. User approved this scope on 2026-11-03.

**Architecture:** Keep the independent FormalRenderer and capture settings unchanged. Extend the reusable Viewport through optional viewer props; the Web wrapper owns display-only state. Existing desktop callers retain their behavior. Use the installed Three.js OrbitControls, without new runtime dependencies.

**Constraints:** Preserve the neo-brutalist style, local rendering and downloads, existing coordinates and dataset schemas. Label uncalibrated dimensions as model dimensions, and meshes as meshes rather than engineering components. Name the branch `web/V4`, application version `4.0.0-web`, displayed release `V4`.

## Shared contracts

`viewer.ts` exports `ViewerPreset = 'home'|'front'|'back'|'left'|'right'|'top'|'bottom'`, `ViewerStyle = 'solid'|'wireframe'|'edges'`, `ViewerCommand = { sequence: number; action: ViewerPreset|'fit'|'zoomIn'|'zoomOut' }`, `ViewerOptions = { enabled: boolean; style: ViewerStyle; command: ViewerCommand }` and `ViewerModelStats = { dimensions: [number,number,number]; meshCount: number; triangleCount: number }`.

Viewport adds optional `viewer?: ViewerOptions`, `onModelStats?: (stats: ViewerModelStats|null)=>void`, retaining all existing required props.

Helpers: `viewerPresetDirection(preset): THREE.Vector3`, `fitViewerCamera(camera, center, radius, aspect, direction?): void`, `getViewerModelStats(root): ViewerModelStats`, `createViewerDisplay(root): {setStyle(style): void; dispose(): void}`.

WebViewport receives `{ model, scene, rotating, onStopRotation, onRotateChange, onDistanceWheel, onPoseChange, onReady, ready }`; it passes only pose-mode gestures to the supplied capture callbacks. BrowserApp retains rotation state because configure() already stops rotation.

## Review focus

- Free observation never changes a frozen or mutable capture draft, including during mode changes and pointer cancellation.
- Narrow screens and fullscreen resize fit the whole model; leaving fullscreen or changing tabs restores layout and input.
- Model loading/retry/switch clears stale stats and disposes controls, geometry overlays and GPU resources.
- Leaving wireframe/edges for capture preview restores solid materials; helpers never reach FormalRenderer.
- Keyboard focus, visible mode labels and mobile controls keep capture changes intentional.
