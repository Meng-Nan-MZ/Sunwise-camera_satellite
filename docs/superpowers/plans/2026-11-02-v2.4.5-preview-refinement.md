# V2.4.5 预览区域整理

用户已确认四项范围并授权实现、验证、提交及上传；不制作安装包。

## 已确认设计

- 将模型标题、视角切换和预览辅助并入一行。模型名称过长时省略并提供完整提示；小窗口将辅助控件收进“预览辅助”，保留可点击尺寸。
- 删除安全框。新增默认关闭的“旋转预览”，仅在彩色模型预览/拖动调姿视角可用。绕竖直轴以俯视逆时针方向缓慢旋转，只改变视口对象的临时显示变换，不写入拍摄姿态、距离、起止关键帧或任务。关闭、切换拍摄视角/模型/模式/页面时停止并恢复设定姿态。手动开始调姿时先停止旋转，继续编辑设定姿态；序列播放与旋转预览不同时开启。
- 中文显示名称统一为“随机姿态批量”“自动旋转序列”“起止姿态序列”；内部模式标识和采集算法保持不变。
- 页脚改成细分隔线与小卫星装饰，缩短高度；原本地保存、提交冻结和已保存结果说明移入设置帮助。

## 实施顺序

1. 先建立旋转时钟行为测试，覆盖帧率无关、停止恢复、长间隔保护，再实现仅在视口生效的旋转。
2. 合并预览栏，增加响应式辅助菜单；更新页脚与设置帮助。
3. 并行统一可见标签、V2.4.5 版本标记及当前用户文档。
4. 构建 UI 与桌面程序，运行单元检查及隔离的原生 WebView2 验收。实际比较旋转开/关的正式 PNG 与姿态参数，检查两主题及 1108×645、960×600 布局，回归拖动/滚轮与模式切换。
5. 独立审查，记录验证证据；提交并将现有 V2 分支及 v2.4.5 标签上传 GitHub。

KIMI、用户数据、旧版验证记录均不修改。所有验收数据保存在忽略的 var 目录。
