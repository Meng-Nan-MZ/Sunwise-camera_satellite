# V2.2.1 Web Formal Capture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax.

**Goal:** 用现有网页引擎正式采集清晰的卫星PNG及一致标签，保留Blender可选对照并实测。

**Architecture:** 后端仍采样、冻结、验证和发布，选择独立渲染后端。内存桥接把单帧交给已有WebView2中的专用Three.js采集场景，Python接收PNG/矩阵后沿用原管线。纯几何投影模块独立验证。

**Tech Stack:** existing Three.js/TypeScript/WebView2, Python/NumPy/Pillow/SQLite; no new production runtime.

**Spec:** docs/superpowers/specs/2026-11-01-v2.2.1-web-capture-design.md
