## 验证发现及修复

首轮和原代码复现记录分别保存在`1793562902465-96136`与`1793563172791-40052`目录。Landsat 9第二姿态的原始2048图只有1个像素为`[9,9,10,255]`，触发严格不透明灰度检查。根因是shader的`mix(RGB,luma,1)`端点浮点运算可能留下通道差，量化后相差1级。

最小修复为捕获模式直接把同一个亮度值赋给RGB三通道，彩色模式保留原色，shader缓存标记更新。未改变素材、光照、采集配置或后端断言。最终同姿态`accepted-render-1793563411202.png`的同一点为`[9,9,9,255]`，全图非灰像素0；36张新增模型原始图全部满足严格检查。

独立审查还推动修复了删除前目录替换竞态、删除成功但响应丢失的UI收敛、关闭重开后的确认范围保留，以及分发工具默认版本同步。上述修复均在最终原生验证之前完成。
