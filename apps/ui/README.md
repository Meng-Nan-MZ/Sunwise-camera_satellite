# 卫星数据工作台界面

React、TypeScript 严格检查、Three.js 和 Vite。应用资源由同源本机服务提供，不从 CDN 获取脚本、字体或模型。依赖版本由 `pnpm-lock.yaml` 固定。

## 开发与构建

使用 Node.js 24（测试使用原生 TypeScript 类型擦除）和 pnpm：

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm build
```

生产文件位于 `dist/`，由 Python 服务直接提供。`pnpm dev` 的 Vite 开发服务器将 `/api`、`/assets/models` 和 `/data` 代理到 `http://127.0.0.1:8765`。

## 约定

- 唯一后端契约为工程的 `docs/architecture/interfaces.md`。
- GLB 几何已在米制机体系 B 中居中，浏览器不再移动、缩放或重新归一化模型。
- 姿态输入为内禀 XYZ 欧拉角，提交主动 B→W 的四元数 `[x,y,z,w]`；相邻操作保持四元数符号连续。
- 拍摄相机在 `(0,0,d)`，+Y 向上，每个模型使用固定短边 FOV：`2 atan(r / (0.8 sqrt(10000²-r²)))`。自由观察使用另一台相机及独立环境补光。
- 正式图像显示 `/data` 下真实保存的 PNG。改变当前场景不会改动所选任务结果。正式单帧按钮提交一个常规单帧任务。
- 覆盖与序列使用服务提供的采样默认值。首版契约未提供序列起止距离或时间步长的输入字段，因此界面只开放契约支持的参数。
- GLB 内嵌纹理由 Three.js 通过 `fetch(blob:)` 解码，服务 CSP 的 `connect-src` 必须包含 `blob:`。模型、纹理、网络、WebGL 和正式图片错误均有可见提示。
- 快速模型切换取消旧请求，丢弃并释放过期解析结果；卸载时清理动画、控件、纹理、几何、材质和 WebGL 上下文。

## 已验证

`pnpm test` 的 5 个测试覆盖标准四元数、跨 180° 符号连续、固定球体视场、嵌套快照冻结、非有限及越界输入拒绝。

2026-09-19 本机浏览器验收：六模型含纹理载入；拍摄/自由观察切换；90° Z 姿态四元数；10–30 km 目标缩放且视场不变；单帧提交和真实 1024² PNG；干净/含噪图像切换；覆盖任务取消；390px 窄屏无横向溢出。正式纹理与 Blender 的程序材质不保证逐像素一致。

构建后的 Three.js 主包约 593 KB（gzip 150 KB），会触发 Vite 默认 500 KB 提示；这是本地打包依赖，不是运行时联网资源。
