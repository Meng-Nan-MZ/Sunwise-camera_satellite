# 四模型几何配准与材质角色配方

这些文件只定义原始几何到既有仿真机体系的配准，以及三款导航卫星的材质**角色**，不复制旧材质颜色、节点或贴图。原始模型没有可信物理单位记录；下列缩放保留既有仿真尺寸，不声称真实卫星尺寸已经标定。

`profiles.json` 是模型对象数组。`source_obj` 相对 `assets/sources/four-satellites/`，`source_sha256` 必须在导入前核验。`source_to_body` 是作用于原始 OBJ 数值坐标的 4×4 仿射矩阵：`p_B = T_BM · [x_OBJ,y_OBJ,z_OBJ,1]`。不要先应用 Blender 默认 OBJ 轴变换再套用该矩阵。

| 模型 | 原始顶点 | 原始面 | 原始 UV 坐标 | 连接分量 | 统一缩放 | 配准最大误差（米） |
|---|---:|---:|---:|---:|---:|---:|
| GPS | 148521 | 154525 | 136022 | 775 | 0.010406253848561923 | 7.89e-7 |
| Galileo | 97570 | 92308 | 50174 | 559 | 0.003928218949440329 | 4.34e-7 |
| GLONASS | 185474 | 177660 | 113695 | 701 | 0.007892539807576877 | 6.94e-7 |
| Sputnik-1 | 143763 | 140952 | 45547 | 150 | 0.016924597837094133 | 1.72e-6 |

四个 OBJ 的全部面角都有 UV；Sputnik 保留原始角 UV，可直接用于随包贴图。连接分量统计按 OBJ 原始共享顶点索引，不合并几何上重合但索引独立的点。

三款导航卫星的顶点数量、顺序与旧版相同。旧资产还叠加了小角度旋转，单独轴置换和包围盒对齐不能可靠重合。配方矩阵由全部对应顶点进行统一尺度、正旋转和平移配准获得；误差逐顶点检查，行列式为正。旧 `blend_sources` 到此前标准 `render.blend` 则只包含包围盒中心平移。

Sputnik 原始 OBJ 与 FBX 顶点顺序不同，不能按相同索引直接匹配。先将随包 FBX 按五个对象名称及其顶点索引匹配旧版；再与 OBJ→FBX 的数值关系 `0.01*(x,-z,y)` 复合，最后逐个验证全部 143763 个 OBJ 顶点到旧版表面的顶点集合。得到的姿态映射是正旋转，未采用镜像。

## NPZ 材质角色

三个 NPZ 的 `roles` 为 `uint8`，长度等于源 OBJ 的原始面数。逐面索引严格对应源文件中 `f` 行的顺序：`0=body MLI`，`1=solar front/back`，`2=aluminium`，`3=radiator`（本次未使用）。另存标量 `source_sha256`、`raw_face_count`，及仅供拓扑审计的 `unmatched_face_indices`、`zero_area_unmatched_face_indices`。使用 `numpy.load(..., allow_pickle=False)` 即可读取。构建器应直接使用这些最终角色，不再叠加按小组件改银色的规则。

当前版本为 **geometry-regions-v2**。实际彩色渲染发现旧版名为 `Photovoltaic` 的材质分区标注的是中央机体，不能当作真实光伏标签；首次按旧标签转移的角色已全部废弃。当前角色只依据原始几何分区和面法线，中央机体默认为金色 MLI，翼板正反宽面为蓝色光伏，板侧边与细长独立支杆为银色。三款原始 OBJ 都只有一个 wire 材质且 MTL 缺失，因此这是仿真材质重建，不声称还原了源作者或制造商材质。

所有规则都作用于**配准前的原始 OBJ 数值坐标**，面位置取原始面角坐标均值，法线由多边形 Newell 面积向量求得。翼板范围如下：

| 模型 | 左右翼 X 范围 | 薄板轴范围 | 另一平面轴范围 | 正反板面方向 |
|---|---|---|---|---|
| GPS | x < -68 或 x > 66.5 | 443.5 ≤ z ≤ 449 | -43 ≤ y ≤ 171 | abs(nz) > 0.95 |
| Galileo | x < -125 或 x > 125 | 9 ≤ z ≤ 16 | -38 ≤ y ≤ 117 | abs(nz) > 0.95 |
| GLONASS | x < 40 或 x > 106 | 150 ≤ y ≤ 173 | 30 ≤ z ≤ 174 | abs(ny) > 0.95 |

在翼板范围内，侧边先置为银色；正反板面还要求单面的两个平面内包围盒跨度都大于 0.3 原始单位，并且不属于细杆连接分量。细杆判定采用连接分量包围盒排序后的跨度 `a ≤ b ≤ c`，满足 `c > 0.02 × 全模型最大跨度`、`b < 0.14c`、`a < 0.10c`。不因一个组件很小或面数很少就把机体表面改为银色。零面积面保留角色 0，由导入器显式跳过。

| 模型 | MLI 面数 | Solar 面数 | Aluminium 面数 | 蓝面左 / 右翼 | 蓝面正 / 反方向 |
|---|---:|---:|---:|---:|---:|
| GPS | 115243 | 7936 | 31346 | 3968 / 3968 | 3968 / 3968 |
| Galileo | 9912 | 16632 | 65764 | 8316 / 8316 | 8316 / 8316 |
| GLONASS | 68532 | 21536 | 87592 | 10784 / 10752 | 10768 / 10768 |

这些是原始面数，包含随后明确剔除的零面积面。已检查两翼和正反面均有蓝面，中央 X 范围没有蓝面；源坐标正交投影也已确认机体金、翼板蓝、连接杆银。零件的精确物理材料仍属未验证部分，未尝试猜测每个螺丝或独立机体附件。

拓扑检查中，GPS 所有 154525 面的顶点列表连顺序都一致。Galileo 有 18 个原始面无法按未清理索引集合匹配，其中 6 个零面积、12 个非零面积；GLONASS 有 32 个，其中 20 个零面积、12 个非零面积。零面积面可以明确跳过；重复的连续角应移除后保留非零面积面。不能把这些差异全部当成退化面删除。未匹配面编号仅供审计，当前材质按上述几何规则独立决定。

早期最近表面法和精确拓扑法都只能转移旧标签，无法证明标签语义。保留相关审计文件只为解释旧方案失效；它们不再是材质角色的有效依据。

完整原始边界、对象/材质数量、面面积与中间尝试位于 `var/model-update/audit/`。最终有效输入是本目录 `profiles.json` 和三个 NPZ；审计目录中的早期纯轴对齐或 Sputnik 按错误顶点顺序的试算不是有效配方。几何重现脚本为审计目录中的 `audit_geometry.py`、`audit_registration.py`、`audit_topology.py`、`audit_sputnik_fbx.py`、`verify_sputnik_obj.py`、`check_missing_faces.py`、`write_recipes.py`。最终材质重现脚本是 **`geometry_roles.py`**；它核验源 SHA、保持矩阵不变，并输出 `geometry-material-roles-audit.json` 和三张 `*-geometry-roles.png`。`write_recipes.py` 最后也会调用它，以防恢复旧的错误语义角色。
